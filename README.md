# 과제 서류 메일 정리 도우미 (시제품)

K-PASS로 받을 수 없는 서류와 K-PASS 마감기(11월 말~연초)에 메일로 들어오는 과제 제출 서류(참여확약서·협약서·재무증빙 등)를
과제 목록에 맞춰 자동 분류하고, **제출현황 엑셀**과 **과제별 폴더(ZIP)** 로 정리합니다.

## 사용 순서
1. **과제 목록 올리기**: 과제번호, 과제명, 주관기관, 해외기관, 이메일 열이 있는 엑셀(.xlsx/.csv)을 올립니다. 열 이름은 자동으로 인식합니다.
2. **메일 올리기**: 두레이 메일 필터로 모은 메일을 `.eml`로 저장해 올립니다. 여러 개를 묶은 `.zip`도 됩니다.
3. **검토**: 자동 분류되지 않은 메일(확인 필요·미분류)만 골라 과제를 지정합니다. 후보 과제를 눌러 바로 확정할 수 있습니다.
4. **내보내기**: 엑셀 현황표(제출현황·메일목록·첨부파일목록)와 과제별 폴더 ZIP을 내려받습니다.

화면의 [가상 데이터로 한 번에 체험하기]를 누르면 가상 과제 30개, 가상 메일 43통으로 바로 써볼 수 있습니다.

## 분류 방식
규칙으로 먼저 판단하고, 애매한 메일만 AI(선택)에 넘깁니다.

| 단서 | 점수 |
|---|---|
| 제목·첨부파일명·본문에 과제번호 | 100 / 95 / 90 |
| 발신자가 과제 연락처 (한 과제에만 등록) | 85 |
| 발신 도메인이 해외기관·주관기관 도메인 (한 과제에만 해당) | 55 |
| 기관명 언급 | 35 |
| 과제명 핵심어 절반 이상 일치 | 최대 30 |

- 80점 이상 **자동 분류**, 45~79점 **확인 필요**, 그 미만 **미분류**
- 비슷한 점수의 후보가 둘 이상이면(예: 같은 해외기관이 여러 과제에 참여) 확인 필요로 둡니다
- 과제번호·발신자·도메인 단서 없이 기관명·과제명 언급만 있으면(개인 메일 등) 자동 확정하지 않습니다
- 답장 인용부(이전 메일 내용)에 있는 과제번호는 무시합니다
- 서류 종류는 첨부파일명 키워드로 나눕니다 (`lib/settings.ts`에서 서류 종류·키워드 수정)

## 정리 규칙
```
과제서류정리_YYYYMMDD/
├─ 과제서류정리_YYYYMMDD.xlsx
├─ P0031001_협동로봇 기반 정밀 조립 자동화 기술/
│  ├─ 참여확약서/P0031001_Nordlicht Institute_참여확약서_20261130_원래파일명.pdf
│  ├─ 협약서/...
│  ├─ 재무증빙/...
│  └─ _메일원문/20261130_M001_제목.eml
├─ 01_확인필요/   (검토하지 않은 메일)
└─ 00_미분류/
```

## 정보 보호
- 올린 파일은 **브라우저 안에서만** 처리하며 서버에 저장하지 않습니다.
- AI 판단을 켜면 메일 제목·본문 일부(인용부 제외, 최대 4천 자)·첨부파일 **이름**만 AI로 보냅니다. 첨부파일 내용은 보내지 않습니다.
- AI가 후보에 없는 과제번호나 없는 서류 종류를 답하면 서버에서 버립니다.

## AI 설정 (선택)
| 환경변수 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | 시제품: Claude API 사용 |
| `AI_PROVIDER=internal` + `AI_BASE_URL` + `AI_MODEL` | 기관 내부 이관: 내부 서버의 OpenAI 호환 모델 서버(vLLM·Ollama 등) 사용 |
| `AI_API_KEY` | 내부 모델 서버에 인증이 필요할 때 |
| `APP_PASSWORD` | 설정 시 AI 호출에 접속 비밀번호 필요 (외부 배포 시 권장) |

AI를 설정하지 않으면 규칙 기반으로만 동작합니다. AI 제공처는 `lib/ai/provider.ts` 한 파일에서만 바뀝니다.

## 기관 내부 서버 이관
`next.config.mjs`가 단독 실행(standalone) 결과물을 만들므로 그대로 Docker 이미지로 묶을 수 있습니다.

```bash
docker build -t mail-collector .
docker run -p 3000:3000 -e AI_PROVIDER=internal -e AI_BASE_URL=http://내부모델서버:8000/v1 -e AI_MODEL=모델명 mail-collector
```

글꼴도 패키지에 포함되어 있어 인터넷이 없는 내부망에서도 화면이 그대로 보입니다.

## 배포 (Vercel)
저장소를 Vercel에 가져오면 바로 배포됩니다. 환경변수는 `.env.example` 참고 (없어도 규칙 기반으로 동작).
